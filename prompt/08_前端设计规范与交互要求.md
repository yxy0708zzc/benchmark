# 08_前端设计规范与交互要求.md（给 Trae 的完整提示词）

本文件是 Trae 生成前端代码时的完整约束文档，涵盖所有页面的布局结构、配色方案、交互细节和视觉风格。

**Trae 使用说明**：本文件是唯一的前端设计规范，所有页面的视觉风格必须统一遵守本规范。配色方案、字体、间距、圆角等全局变量应在 CSS 中统一定义。所有页面需适配 1920×1080 及以上分辨率，同时兼顾 1440×900。


## 第一部分：全局设计语言

### 1.1 设计理念

**关键词**：专业、清晰、高效、可信赖

本项目是 Benchmark 测试工具，面向 AI 研究者和开发者，前端风格应当：
- 传递“科学严谨”的视觉感受（非娱乐化）
- 信息层级清晰，减少认知负担
- 数据可视化为主，文本为辅
- 中性偏冷色调，避免花哨

### 1.2 字体体系

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| H1 | 24px | 600 | 1.4 | 页面主标题 |
| H2 | 18px | 600 | 1.5 | 区块标题 |
| H3 | 15px | 600 | 1.5 | 卡片标题 |
| Body | 14px | 400 | 1.6 | 正文、描述 |
| Small | 12px | 400 | 1.5 | 辅助信息、时间戳 |
| Code | 13px | 400 | 1.5 | 代码、数据展示 |

字体族：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`

### 1.3 色彩系统

| 颜色名称 | 色值 | 用途 |

## 第七部分：与后端接口约定

### 7.1 前端调用后端 API 的统一前缀

所有 API 请求统一使用 `/api/` 前缀，前端开发时配置代理：

```javascript
// 开发环境代理配置
const API_BASE = '/api';
```

### 7.2 错误处理

- 网络错误：显示 Toast 提示“网络连接失败，请检查服务是否运行”
- 4xx 错误：显示后端返回的 `detail` 信息
- 5xx 错误：显示“服务器内部错误，请查看后端日志”

### 7.3 Toast 提示规范

- 位置：顶部居中
- 背景色：深色（`#2D3138`）
- 文字色：白色
