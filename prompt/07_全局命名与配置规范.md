# 07_全局命名与配置规范.md（给 Trae 的完整提示词）

本文件是 Trae 生成代码时的**全局命名与配置索引**，涵盖所有字段名、API 路径、文件夹路径、数据库表名、配置项。所有命名以本项目书为准，不混用任何参考代码中的命名。

**Trae 使用说明**：本文件是贯穿所有模块的“单一事实来源”（Single Source of Truth）。生成任何代码时，字段名、路径名、表名必须严格遵照本文件。如有歧义，以本文件为准。


## 第一部分：字段命名总表

### 1.1 核心业务字段（全局统一）

| 中文含义 | 字段名 | 类型 | 说明 |
|----------|--------|------|------|
| 车次号 | `train_num` | TEXT | 显示车次号，如 `G1`、`G2` |
| 车次内部编号 | `train_no` | TEXT | 12306 内部标识，仅爬虫和数据库关联使用，**不对外暴露** |
| 车站电报码 | `station_id` | TEXT | 全局唯一标识，如 `VNP`（北京南） |
| 车站中文名 | `station_name` | TEXT | 如 `北京南` |
| 经停站序号 | `stop_no` | INTEGER | 该车次的第几站，从 1 开始 |
| 经停站时间 | `stop_time` | TEXT | 格式 `HH:MM`，有抵达取抵达，无抵达取出发 |
| 车站大屏中的车次号 | `stop_num` | TEXT | 与 `train_num` 含义相同，仅在车站大屏上下文使用 |
| 二等座 | `class2` | TABLE | 经济型座位 |
| 一等座 | `class1` | TABLE | 舒适型座位 |
| 特等座 | `class0` | TABLE | 可躺型座位 |
| 余票数量 | `tickets` | INTEGER | 值域 0~30 |

### 1.2 字段命名使用场景对照表

| 使用场景 | 出发站字段 | 到达站字段 | 车次字段 | 车站字段 |
|----------|-----------|-----------|----------|----------|
| 车次概览（`/api/train`） | - | - | `train_num` | - |
| 车站概览（`/api/station`） | - | - | - | `station_id`, `station_name` |
| 车次详情-顶层信息 | `from_station_id`, `from_station_name` | `to_station_id`, `to_station_name` | `train_num` | - |
| 车次详情-经停列表 `data` | - | - | - | `stop_no`, `stop_name`, `stop_id`, `stop_time` |
| 车站详情（大屏） | - | - | `stop_num` | `station_no`（电报码）, `station_id`（站名） |
| 余票查询 | `from_station_id` | `to_station_id` | `train_num` | - |
| 两站之间查询 | `from_station_id` | `to_station_id` | `train_num` | - |

### 1.3 关键区别说明（防止混淆）

| 概念 | 字段名 | 使用位置 |
|------|--------|----------|
| 车站电报码 | `station_id` | 车站概览、车次详情顶层、余票表、两站查询 |
| 车站中文名 | `station_name` | 车站概览、车次详情顶层 |
| 经停站电报码 | `stop_id` | **仅在车次详情的经停列表 `data` 内部使用** |

| 经停站序号 | `stop_no` | **仅在车次详情的经停列表 `data` 内部使用** |
| 车站大屏中的电报码 | `station_no` | **仅在车站详情（大屏）中使用** |
| 车站大屏中的车次号 | `stop_num` | **仅在车站详情（大屏）中使用** |

### 3.3 metadata.json 结构（必读）

```json
{
  "q001": {
    "status": "draft | completed",
    "created_at": "2026-06-29 10:00:00",
    "modified_at": "2026-06-29 15:30:00",
    "train_count": 1200,
    "has_auto_generated": false
  }
}
```

- `status`：`draft` 为草稿（测试器不显示），`completed` 为已完成（测试器可加载）
- `train_count`：该题目中包含的车次数量（即 `trains` 表中所有 G 车次总数）
- `has_auto_generated`：是否由 auto出题器生成

### 4.3 CREATE TABLE 语句（关键表）

**stations**：

```sql
CREATE TABLE stations (
    station_id TEXT PRIMARY KEY,
    station_name TEXT NOT NULL
);
```

**trains**：

```sql
CREATE TABLE trains (
    train_num TEXT PRIMARY KEY,
    train_no TEXT UNIQUE NOT NULL
);
```

**train_stops**：

```sql
CREATE TABLE train_stops (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    train_num TEXT NOT NULL,
    stop_no INTEGER NOT NULL,
    station_id TEXT NOT NULL,
    station_name TEXT NOT NULL,
    stop_time TEXT NOT NULL,
    FOREIGN KEY (train_num) REFERENCES trains(train_num) ON UPDATE CASCADE,
    FOREIGN KEY (station_id) REFERENCES stations(station_id) ON UPDATE CASCADE,
    UNIQUE(train_num, stop_no)
);
```

**class2（class1/class2 结构相同）**：

```sql
CREATE TABLE class2 (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    train_num TEXT NOT NULL,
    from_station_id TEXT NOT NULL,
    to_station_id TEXT NOT NULL,
    tickets INTEGER NOT NULL CHECK (tickets >= 0 AND tickets <= 30),
    UNIQUE(train_num, from_station_id, to_station_id)
);
```
