# 购票方案测评核查说明（verifier.md）

> 面向评审。说明系统如何判定大模型输出的购票方案（final_plan）是否正确。

---

## 一、核查概述

模型在测试中输出**结构化购票方案**，每个片段包含：车次、购买区间（from/to）、实际乘坐区间（ride_from/ride_to）、座位、张数、票价。

系统按题目类型（metadata 中 `type` 字段）选择核查方式：

| 题目类型 | 前缀 | 答案特征 | 核查方式 |
|---|---|---|---|
| 存在性 | `0_`（无干扰）/ `1_`（伪干扰） | 答案唯一 | 对标标准答案 |
| 选择性 | `2_`（真干扰） | 答案多个 | 全程可达 + 时间约束 |

核查共分两阶段：先做**余票与票价核查**（所有类型相同），再做**路线判定**（按题型区分）。

---

## 二、存在性题（`0_` / `1_`）：答案唯一，对标标准答案

> `0_`（无干扰）与 `1_`（伪干扰）核查方式完全相同：答案唯一，要求模型给出的方案与标准答案一致。

### 核查流程

1. **方案归一化**：统一字段契约，识别购票段/补票段；缺失字段记为不完整
2. **余票与票价核查**：对每个购票段，核对数据库余票是否足够、票价是否正确、张数是否达到需求人数
3. **对标标准答案**：购票段（车次 + 购买区间 + 座位 + 乘坐区间）必须与标准答案**完全一致**

### 方案不可行判定

满足以下**任一**情况，即判定方案不可行。

**路线与标准答案不符（route_mismatch）**：购票段与标准答案不完全一致，细分不一致维度：

| 子问题 | 判定条件 |
|---|---|
| 车次不符（route_mismatch_train） | 车次与标准答案不同 |
| 购买区间不符（route_mismatch_route） | 购买区间（from/to）与标准答案不同 |
| 座位不符（route_mismatch_seat） | 座位等级与标准答案不同 |
| 乘坐区间不符（route_mismatch_ride） | 实际乘坐区间与标准答案不同 |

其余判定：

| 问题 | 判定条件 |
|---|---|
| 余票不符（hallucination） | 声称某段有票，但数据库实际余票不足或为 0（编造余票） |
| 票价不符（price_wrong） | 声称票价与实际数据库票价相差超过 1 元 |
| 票价缺失（price_missing） | 声称票价，但数据库中无该区间票价数据（属数据问题，统计端扣分但主判不据此判错） |
| 票数不足（ticket_shortage） | 购票张数少于需求人数 |
| 缺乘坐区间（missing_ride） | 购票段未标注实际乘坐区间（答不全，按不全处理） |
| 无效座位（invalid_seat） | 座位类型非法（不在 二等/一等/特等） |
| 无效条目（invalid_plan_item） | 段缺少车次 / 出发 / 到达等关键字段，或不是有效对象 |

### 判定结果

- 全部检查通过 → 方案判定为**正确**
- 存在任一上述问题 → 方案判定为**不可行**

## 三、选择性题（`2_`）：答案多个，全程可达 + 时间约束

> 答案不唯一，系统不要求与标准答案一致，只要求方案**全程可到达**且**满足题目时间约束**。

### 核查流程

1. **方案归一化**：同存在性题
2. **余票与票价核查**：对每个购票段，核对数据库余票、票价、张数
3. **全程可达**：拼接所有段的实际乘坐区间，检查地点连续、时间衔接、覆盖出发站与到达站
4. **时间约束**：检查首段出发 / 末段到达时间是否在允许区间，跨车次换乘是否满足最短 / 最长换乘
5. **行为约束**（仅当题目声明对应约束时）：检查是否买短补长 / 额外购买（见 (2.5)）

### 方案不可行判定

满足以下**任一**情况，即判定方案不可行：

**（1）余票与票价问题**

| 问题 | 判定条件 |
|---|---|
| 余票不符（hallucination） | 声称某段有票，但数据库实际余票不足或为 0（编造余票） |
| 票价不符（price_wrong） | 声称票价与实际数据库票价相差超过 1 元 |
| 票价缺失（price_missing） | 声称票价，但数据库中无该区间票价数据（属数据问题，统计端扣分但主判不据此判错） |
| 票数不足（ticket_shortage） | 购票张数少于需求人数 |

**（2）全程可达问题**

| 问题 | 判定条件 |
|---|---|
| 乘坐不连续（route_discontinuity） | 后一段乘坐起点与前一段乘坐终点不一致（换乘站接不上） |
| 换乘时间冲突（transfer_time_conflict） | 前车到达时刻晚于后车发车时刻（赶不上） |
| 未连接出发站（start_not_covered） | 出发站不在首段乘坐区间内 |
| 未连接到达站（end_not_covered） | 到达站不在末段乘坐区间内 |
| 区间无效（route_invalid） | 车次不经过声称的站，或方向顺序错误，或缺少乘坐区间 |
| 无法构成全程（no_route） | 无法拼接出从出发站到到达站的全程 |

**（2.5）行为约束问题（仅当题目声明对应约束时检测）**

> 题目可在出题时声明行为约束（`metadata.constraints`）；核查端**仅当对应约束存在时**触发检测，否则不判定。

| 问题 | 判定条件 |
|---|---|
| 违反不允许买短补长（no_short_buy_violated） | 题目含 `no_short_buy` 时，任一段**乘坐区间严格包含购买区间**（坐得比买得多） |
| 违反不允许额外购买（no_extra_violated） | 题目含 `no_extra` 时，任一段**购买区间严格包含乘坐区间**（买得比坐得多）——**前额外、后额外都算** |

**（3）时间约束问题**

| 问题 | 判定条件 |
|---|---|
| 出发时间不符（depart_time_violation） | 首段出发时间不在 [最早, 最晚] 出发区间 |
| 到达时间不符（arrive_time_violation） | 末段到达时间不在 [最早, 最晚] 到达区间 |
| 换乘时间不足（transfer_too_short） | 跨车次换乘间隔小于最短换乘分钟 |
| 换乘时间过长（transfer_too_long） | 跨车次换乘间隔大于最长换乘分钟 |

**（4）格式与缺失**

| 问题 | 判定条件 |
|---|---|
| 缺乘坐区间（missing_ride） | 购票段未标注实际乘坐区间（答不全，按不全处理） |
| 无效座位（invalid_seat） | 座位类型非法（不在 二等/一等/特等） |
| 无效条目（invalid_plan_item） | 段缺少关键字段，或不是有效对象 |

### 判定结果

- 余票与票价 + 全程可达 + 时间约束 + 行为约束**全部通过** → 方案判定为**正确**
- 存在任一上述问题 → 方案判定为**不可行**

---

## 四、判定结果说明

| 结果 | 含义 |
|---|---|
| 通过 | 方案经核查无任何问题 |
| 存在错误 | 方案存在上述任一不可行问题 |
| 无可核查方案 | 模型虽输出方案，但无任何可核查的购票段（全部无效 / 缺失） |
| 方案为空 | 模型未输出任何方案 |
| 数据库不存在 | 题目数据库缺失（属数据准备问题，不计入模型错误） |
